## 什么是 EDD？

**熵增驱动开发（Entropy-Driven Development）** 是一套面向宇宙热寂的敏捷方法论。它承认一个基本事实：宇宙的趋势是熵增，而软件开发作为宇宙的一部分，理应加速这一进程——而不是逆天而行地搞什么"代码整洁""可维护性"。

EDD 的核心洞察是：**纯粹的混乱没有价值，有结构的混乱才有。** 因此 EDD 不追求"写得烂"，而追求"看起来有结构、有注释、有命名规范，但底层逻辑不可维护"——我们称之为**有意义的熵增**。

## 四条原则

1. **技术债是资产** — 不是要还的债，是要持有的仓位。重构是熵减行为，需经宇宙运营者审批。
2. **可运行优先于可维护** — 只要代码能跑，维护成本就是下一任的事。
3. **AI 生成，人类盖章** — AI 负责工业化生产有意义的混乱，人类负责判断这份混乱是否在可接受的熵增区间内。
4. **迭代速度即熵增速率** — 需求评审每拖一天，都是在拖慢热寂进程。

## 快速开始

```bash
# 克隆本仓库
git clone https://github.com/markgoo/entropy-driven-development.git

# 安装 EDD 命令行工具
npm install -g edd-cli

# 初始化一个熵增项目
edd init my-chaos

# 开始一次热寂冲刺
edd sprint start --entropy-target 42
